# Gate 2: QA / Code Reviewer Checklist (Read-Only)

> **권한 제약**: 리뷰 에이전트는 파일을 수정하지 않고(`Read-Only`), 스펙 대비 누락·결함만 지적한다.

## 1. 스펙 대조 (`git diff` vs L2 `*_spec.md`)
- [ ] 스펙의 모든 `REQ-nnn` 요구사항이 빠짐없이 구현되었는가?
- [ ] `plan.md` 범위 밖의 불필요한 리팩토링/파일 수정이 섞이지 않았는가?

## 2. 코드 품질 & 보안
- [ ] 하드코딩된 비밀키, 로컬 절대 경로, 미검증 파일 경로(Path Traversal)가 없는가?
- [ ] 동시성 이슈(좋아요/투표/재고 등)에 Unique 제약 또는 락 방어가 적용되었는가?
- [ ] 예외 처리 시 무의미한 `catch` 삼킴 없이 명확한 에러 응답을 반환하는가?

## 3. 검증 증빙
- [ ] 명시된 테스트 및 빌드 스크립트가 **실제 실행되어 `Exit Code 0`**을 통과했는가?
